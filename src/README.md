# Source Layout

- `index.ts`: Loader-facing namespace and public exports.
- `config.ts`: serializable conservative deployment policy.
- `runtime.ts`: Cordis activation and scoped registrations.
- `runner.ts`: fresh-child orchestration and strict verifier boundary.
- `projection.ts`: immutable DSH session-to-step projection.
- `policy.ts`: pure correction, completion, stagnation, and budget state machine.
- `report.ts` / `prompt.ts`: bounded report contract and child prompt.
- `tools.ts`: canonical `verified_ralph` model tool and generic rendering.
